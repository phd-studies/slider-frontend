# 3D Circular Carousel

This project is a 3D circular carousel built with HTML, CSS, and JavaScript.

## Features

*   **3D Carousel:** A circular carousel that displays items in a 3D space.
*   **3D Scene Rotation:** The entire scene can be rotated in 3D to view the carousel from different angles.
*   **Layered Text Effect:** A "hollow" text effect is layered in the center of the carousel.

## How to Run

1.  Clone the repository.
2.  Open the `index.html` file in your web browser to see the carousel in action.
3.  Click and drag the mouse to rotate the scene in 3D.
